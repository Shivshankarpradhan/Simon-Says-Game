🕹️ Simon Says Game
A fun and interactive memory game where the player must follow the color sequence shown by the computer. Inspired by the classic Simon Says toy!

🚀 Features
Dynamic color sequence generation

Level-based difficulty

Sound and visual feedback

Responsive for desktops

🛠️ Tech Stack
HTML
CSS
JavaScript


📂 File Structure
/simon-says-game
│
├── index.html      # Main HTML file
├── style.css       # Styles for the game
├── game.js         # Game logic in JavaScript
└── README.md       # Project overview (you are here)

🎮 How to Play
Press any key to start the game.

Follow the sequence of colors shown.

Click the buttons in the exact order.

If you click the wrong color, the game ends and shows "Game Over".

Try again and beat your previous level!
